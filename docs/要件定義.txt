# 要件定義

# 1.1 システム概要

# 本システムは、一人暮らしの大学生（主に就職活動や将来の設計を控えた時期）をメインターゲットとし、居住地選択における先入観を客観的データによって変容させるためのWebベースの自己リフレクション型教材システムである。

# 1.2 開発目的と背景（ID理論的アプローチ）

# 若年層が抱きがちな「なんとなく都会が良い」「地方は不便で稼げない」という固定観念（初期スキーマ）に対し、インストラクショナル・デザイン（ID理論）の**ARCS**モデルを適用し、段階的に認知を揺さぶる。

# 教材の前後で同一の質問を行う「Before / After 比較検証機能」を搭載し、学習者の判断基準がどう変容したかを定量・定性データとして厳格に測定・収集することを目的とする。

# 1.3 対象地域（検証モデル都市）

# 学習者にステレオタイプな二項対立（都会か田舎か）をさせず、グラデーション（濃淡）を持った思考を行わせるため、以下の3都市をターゲットとして固定する。

# 都市（利便性特化型）： 大阪府大阪市

# 準都会（バランス型）： 大阪府河内長野市

# 地方（自然・環境重視型）： 兵庫県西脇市

# 1.4 機能要件（Functional Requirements）

# 1.4.1 画面構成・シナリオ制御機能

# 一本道遷移の強制： ストーリーの文脈を正しく体験させるため、G00（トップ）からG05（最終）までスキップできない一本道の遷移制御を行う。

# 次へボタンの動的活性化： 各ページで指定された「学習タスク（入力やクイズへの回答）」を完了するまで、次のページへ進むボタンはクリック不可（非活性）とする。

# 1.4.2 認知的バイアス排除のための動的表示制御（★最重要）

# 第**2.1**章（お金）におけるネタバレ防止： クイズに回答して客観的データ（解説）が表示されるまで、ページ下部に配置されている価値観クエスチョン（最も重視する項目）をプログラムで完全非表示（隠蔽）とする。

# 第**5**章（再意思決定）における誘導防止： 学習者がQ1〜Q4（再回答と理由など）を入力し終えるまで、ページ下部にある「都市別プロフィール（一種の答え合わせ・タイプ診断）」を完全非表示（隠蔽）とする。

# 1.4.3 データ入力・測定機能

# **Before**データ（導入時）： 学習前の都会の定義、将来住みたい場所、その理由、地方への抵抗感を収集する。

# **After**データ（最終時）： 3都市を学んだ後の将来住みたい場所、その理由、判断基準の変化度、影響を与えた因子、今後の活動意欲を収集する。

# 1.4.4 データ永続化機能

# 外部サーバーへの依存を減らし、フロントエンドのみで完結させるため、収集した Before / After データを ⁠localStorage⁠ へオブジェクト形式で一元保存する。

# 1.5 非機能要件（Non-Functional Requirements）

# 1.5.1 ユーザビリティおよび認知的負荷の低減

# 1画面における情報量を制限し、スクロールによる「先の情報の意図しない目視（ネタバレ）」を防ぐ。

# 教材内で提示される自治体の公式ホームページ等への外部リンクをクリックした際、教材システム自体が上書きされて離脱するのを防ぐため、必ず別タブ（⁠target="_blank"⁠）で開く仕様とする。

# 1.5.2 動作環境

# 対象ブラウザ：Google Chrome, Microsoft Edge, Safari 各最新版（PCおよびスマートフォン環境を想定）

# 📐 2．基本設計書（外部設計）

# 2.1 画面遷移図（構造定義）

# ブラウザの「戻る」によるデータの不整合を防ぐため、状態管理を伴う単一方向遷移とする。
